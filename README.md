# Academic Website Workshop Starter

1. Replace every instance of `Your Name`.
2. Replace the example research title and short text.
3. Add your résumé PDF beside `index.html` and rename it `resume.pdf`.
4. Replace the two publication examples on `publications.html`.
5. Upload this folder's three web files and your `resume.pdf` to the root of your `username.github.io` repository.

Everything in a public GitHub repository and on GitHub Pages can be viewed by anyone. Do not add unpublished work, private data, or a CV containing information you do not want public.
